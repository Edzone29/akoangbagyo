# Ako ang Bagyo

A standalone, browser-based storm and lyric animation for **“Ako ang Bagyo” by SHEAN**. The page is built with HTML, CSS, and Canvas JavaScript; it has no build step or external dependencies.

## Run locally

Open `index.html` in a modern browser. Press **Play** when the song reaches about **1:48.8** to align the animation with this excerpt. The page does not play or detect audio, and the lyric timings are approximate.

Use **Pause** to pause the lyrics, **Restart** to replay, or drag the timeline to seek. The **Space** key toggles play/pause and **R** restarts.

## Deploy on Vercel

Import this GitHub repository as a new Vercel project. It is a static site: use the repository root, leave the build command empty, and deploy. Vercel will serve `index.html` as the site entry point.
